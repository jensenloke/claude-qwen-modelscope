# First coding task

Open this repository in a terminal and run `claude-qwen`.

Ask: “Read README.md and summarise what this project does. Do not change files.”
Confirm a Read tool call and an answer. Then try `claude-qwen --thinking` with the
same task. For a local edit/test exercise, ask it to add a pure Python function
that formats a greeting, write a meaningful test, and run it in a disposable folder.

For Brave, request one search and inspect the actual tool call and source URL.
For DevTools, use a local demo application and inspect the browser result.
